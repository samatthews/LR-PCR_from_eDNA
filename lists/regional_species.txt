# Regional species list for lrpcr_assign.py (added Oct 8, 2026).
# A read assigned to a species NOT on this list is reported at genus level instead.
# Applied to both assays (LR-PCR and MiFish). One species per line; text after # is ignored.
#
# Region: Salish Sea (Pietsch & Orr 2019, Fishes of the Salish Sea). The list covers every
# species detected so far in either assay that occurs in the region, every species on the
# Seattle Aquarium tank list, the local species used by the LOCAL rules in lrpcr_assign.py,
# and other common Salish Sea fishes. It is NOT a complete checklist: lrpcr_assign.py prints
# every species it moves to genus level, so check that printout after each run and add any
# regional species that should have been kept.
